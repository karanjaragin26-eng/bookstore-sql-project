# 📚 Bookstore Database Project (PostgreSQL)

## Overview
This project simulates a bookstore/e-commerce system using **PostgreSQL**.  
It includes three relational tables:
- **Books**: Book details (title, author, genre, year, price, stock)
- **Customers**: Customer information (name, email, city, country)
- **Orders**: Order details (customer, book, date, quantity, total amount)

## Features
### 🔹 Basic Queries
- Retrieve books by genre
- Find books published after 1950
- List customers from Canada
- Show orders placed in November 2023
- Calculate total stock and revenue
- Find most expensive/lowest stock book
- Orders exceeding $20

### 🔹 Advanced Queries
- Total books sold per genre
- Average price of Fantasy books
- Customers with at least 2 orders
- Most frequently ordered book
- Top 3 expensive Fantasy books
- Quantity sold by each author
- Cities of customers spending > $30
- Customer who spent the most
- Stock remaining after fulfilling orders
